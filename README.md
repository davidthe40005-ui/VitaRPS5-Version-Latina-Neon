<img width="960" height="544" alt="1000874349" src="https://github.com/user-attachments/assets/21ab921d-bab1-44a5-9fdb-4211cf4a62c4" />🎮 VitaRPS5 v4.2.2 – Versión Latina Neón

Una adaptación de VitaRPS5 para PlayStation Vita que incorpora traducción al español latino y una personalización visual con efectos Neón.

✨ Características

- 🇲🇽 Interfaz traducida al español latino.
- 💙 Personalización visual estilo Neón.
- 🌟 Efectos Neón en la pantalla de inicio.
- 🎨 Detalles visuales personalizados en la barra superior.
- 🎮 Basado en VitaRPS5 v4.2.2.
- 📦 Aplicación compilada en formato VPK.
- ✅ Compilado e instalado, con funcionamiento comprobado en una PS Vita real.

📸 Capturas de pantalla

Las imágenes de este repositorio muestran la interfaz, la traducción y los efectos visuales de esta versión.

📥 Descarga e instalación

Archivo: "VitaRPS5-v4.2.2-version-latina-neon.vpk"

1. Entra en los archivos del repositorio.
2. Descarga el archivo VPK.
3. Transfiérelo a tu PS Vita.
4. Abre VitaShell.
5. Busca el archivo VPK y presiona X para instalar.
6. Ejecuta VitaRPS5 desde el menú LiveArea.

Requisitos: PlayStation Vita con HENkaku o un entorno de firmware personalizado compatible.

🛠️ Compilación

Esta versión fue compilada utilizando Termux y VitaSDK.

El proyecto incorpora modificaciones de traducción al español latino y personalización visual sobre el código fuente de VitaRPS5.
